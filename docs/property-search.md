## 自動実行（2026-11-07 運用者「立ち上げたら自動で・1日1回・2件まで」）

- Claude Code を**立ち上げたとき**（`~/.claude/settings.json` の SessionStart フック・matcher `startup`）に `scripts/property-auto.mjs` が走る。
  今日（日本時間）まだなら裏で `claude -p` を起動し、この手順書どおりに探して送る。立ち上げた画面には「🏠 今日の物件探しを裏で始めました」と出るだけ。
- 1日1回＝`.property-auto.json` の `lastRun`。**失敗したら済みにしない**（次に立ち上げたときにもう一度）。ログは `.property-auto.log`。状態は `node scripts/property-auto.mjs --status`。
- 🔴 自動のときは上限（429）をリセットしない。条件に合う物件が無ければ送らない。
- 止める＝settings.json の SessionStart を消す。配線だけ確かめる＝`PROPERTY_AUTO_TEST=1`（探さずに「OK」と答えさせる）。

## 送り方

- **1日1〜2件**（運用者の指示）。サーバー側も `TALK_PROPERTY_MAX_PER_DAY` の既定を 2 にしてある。
- 同じ物件は送らない（URL／物件名＋間取りで判定・サーバー側）。
- `memo` に「条件に合う理由」を短く。三軒茶屋までの時間（乗り換え駅）も書く。
- 掲載が今も出ているか（募集終了でないか）をページで確かめてから送る。
