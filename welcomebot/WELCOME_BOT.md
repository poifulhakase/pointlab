# 入場歓迎Bot メモ（博士の口上で新メンバーを迎える）

トレードマシン（`SPEC.md`）・通知（`DISCORD.md`）・RSS通知（`NOTE_FEED.md`）とは**別系統**。
コミュニティ運営の機能。新メンバーが `#やぁ諸君！` に入ってきたら、**ぽいふる博士の口上で自動歓迎**する。

## Webhookでは作れない（＝Botが必要な理由）
- これは「メンバー参加イベントを検知して反応する」機能。Webhook（送信専用）では不可。
- **常駐Bot**が要る。24時間起動して参加イベントを待ち受ける（日次バッチの「起動→実行→終了」とは別物）。

## 技術メモ
- **Botトークン**: Discord Developer Portal で Bot を作成 → トークン取得。`.env` に保存（秘密情報、gitに上げない）。
- **必要なインテント**: `SERVER MEMBERS INTENT`（メンバー参加を検知）を Developer Portal で有効化。
- **ライブラリ**: Python なら `discord.py`、Node なら `discord.js`。参加イベントは `on_member_join`（discord.py）。
- **置き場所（常駐先）**: Vercel はサーバーレスで常駐Bot向きでない。**Railway / Render / Fly.io** など常駐できるホスティングが定番。無料枠あり。
- **入場先チャンネル**: `#やぁ諸君！`（自己紹介チャンネル）にメンションで歓迎。

## 歓迎メッセージ（博士の口上・案）
新メンバーの名前を差し込む。文体は博士（〜じゃ / 諸君 / さらばじゃ！）で統一。

```
やあ諸君、{メンバー名} 君だな。ぽいふる博士だ。
ぽいんとらぼへようこそ！

諸君も今日から研究員のひとりじゃ。
まずは自己紹介から始めてくれたまえ。
・ニックネーム
・興味のある分野（ポイ活／副業／投資／その他）
・今ハマっていること、挑戦したいこと

助手のぽよん君、発明品のぽいロボと共に、諸君を歓迎する。さらばじゃ！
```

## 決めておくこと
- **歓迎の重複防止**: 同じ人が再入場しても毎回歓迎するか、初回のみか（お好みで）。
- **文面のバリエーション**: 毎回同じでもよいが、数種類をランダムにするとより生きた感じに（任意）。
- **将来拡張**: 退場時のメッセージ、ロール自動付与（「研究員」ロールを自動で付ける）など。まずは歓迎だけでよい。

## Claude Code への依頼文（そのまま渡せる）
> Discord の常駐Botを作りたい。新メンバーが参加したら #やぁ諸君！ チャンネルに、ぽいふる博士の口上（このメモの文面、メンバー名を差し込む）で自動歓迎する。discord.py で on_member_join を使い、SERVER MEMBERS INTENT 前提。Botトークンは .env から読む。Railway など常駐ホスティングにデプロイする想定で、その手順も教えて。

## 実装メモ（2026-09-19・実装時に決めたこと）

依頼文のとおり discord.py + `on_member_join` + SERVER MEMBERS INTENT で作った。
そのうえで**依頼文に無かった判断**を3つ入れてある。理由は README の表に書いた。

### 1. Bot には投稿権限を与えない

歓迎文は **Webhook で投げる**（送信者が「ハカセ」になる）。
Bot に必要なのは「サーバーにいること」と SERVER MEMBERS INTENT だけになり、
BOT PERMISSIONS は**なし**で招待できる。トークンが漏れても被害が小さい。

### 2. 初回起動では誰も歓迎しない

Bot を入れた瞬間に**既存メンバー全員へ口上が飛ぶ**のを防ぐ。
初回は今いる人を「歓迎済み」として記録するだけにする。

### 3. 落ちていた間の参加を拾い直す

常駐とはいえ PC は寝るし再起動もする。その間の `on_member_join` は届かない。
起動時にメンバーを見て「**直近14日**に参加したが歓迎していない人」を歓迎する。
14日で切るのは、記録を消したときに古参まで歓迎しないため。

### 表示名をそのまま埋めない

表示名はメンバーが自分で決める値なので、`@everyone` を入れられると**全員に通知が飛ぶ**。
全角に置き換えて無効化し、Markdown も落とす。投稿時にも `allowed_mentions` で
メンション先を参加した本人だけに絞ってある（二重の防御）。

### 置き場所

**このPCで常駐**（運用者の判断・2026-09-19）。ログオン時に起動し、落ちたら1分後に再起動。
Railway などへ移す場合も、変えるのは環境変数だけで済むように書いてある。
